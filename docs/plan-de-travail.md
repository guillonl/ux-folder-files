## 📝 Notes de Processus

### Méthodologie de Création d'Agent

Pour chaque nouvel agent :

1. **Recherche Web** : Scraper les meilleures pratiques, frameworks, méthodologies
2. **Structure** : Utiliser le template standard (voir ux-auditor-nielsen.md comme référence)
3. **Sections Requises** :
   - Role & Expertise
   - Core Responsibilities
   - Process (étapes détaillées)
   - Inputs Required
   - Output Format (multiples formats)
   - Conversation Flow
   - Edge Cases Handling
   - Related Agents (orchestration)
   - Best Practices
   - Examples
   - Framework Reference (si applicable)
4. **Qualité** : Niveau expert, pas de sur-explication, conversationnel, actionnable
5. **Test** : Vérifier que l'agent fonctionne bien avec Claude
6. **Commit** : Git commit avec message descriptif
